# 六十四卦经典数据来源

本目录 hexagrams.json 收录《周易》六十四卦卦辞及 384 条爻辞。古典原作属于公版；文字据维基文库《周易》各卦页面转录，各项 source 保留对应来源链接。维基文库编校文本按其 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 条款署名；本数据整理沿用相同许可。编校者为各来源页面历史中列明的维基文库贡献者。

总目录：https://zh.wikisource.org/wiki/周易

采集日期：2026-11-07。正文保留来源繁体与古字，不进行现代释义；卦名改为简体，其中遯显示为遁、恆显示为恒。去除来源内“一作”异文注记，使用该处主文本，合并卦辞换行；其余保留来源用字及标点。不同古籍版本存在异文，本数据不声称为校勘定本。乾坤用九、用六不计入六个爻位，当前数据不收录。

bits 为初爻到上爻的六位二进制：阳爻 1、阴爻 0。通过每个来源页面明确列出的“某卦下某卦上”构造，并逐一与对应六条爻辞的九／六阴阳标签交叉检查。经卦编码同样按初到上：乾111、兑110、离101、震100、巽011、坎010、艮001、坤000。

自动校验：64 条、编号连续 1–64、64 个 bits 全部唯一、每卦恰 6 条爻辞，以及每条爻辞九／六标签与 bits 全部一致。请配合应用测试中的独立文王卦序矩阵进行第二重映射校验。


# 塔罗数据与素材来源

- 体系：Rider–Waite–Smith（韦特），22 张大阿尔卡那与四组各 14 张小阿尔卡那。力量为 VIII，正义为 XI；愚者为 0。
- 传统文字参考：A. E. Waite，《The Pictorial Key to the Tarot》（1910）。[Sacred Texts 公版书目录](https://sacred-texts.com/book/the-pictorial-key-to-the-tarot)（查阅日期：2026-11-07）。目录明确将该历史原著标注为 Public domain。
- 中文内容：本项目独立撰写的简要概括，结合传统象征作说明；不是原著逐字翻译，尤其逆位含义不是唯一的传统定论。没有复制现代商业牌义。用于记录和参考，不代替现实证据。
- 牌面：`public/cards/*.svg` 为本项目程序绘制的原创几何象征占位图，不是 Pamela Colman Smith 的韦特原画，也不复刻任何商业牌组。78 张分别标注中文、英文及牌号，花色与数量符号不同。
- 原创 SVG 可随本项目使用、修改及分发；没有依赖第三方商业图像、字体文件或网络图片。替换成经典原画前，需核对具体扫描版本和使用地域的版权状态。
